# ROBOT IDEA MATRIX

Making 01 `창작 아이디어 수렴하기 #2`용 정적 웹 프로그램입니다.

## 이번 색상 수정
- PDF 및 인쇄 결과의 매트릭스 제목, 평가 기준, 아이디어 이름, 점수, 합계를 모두 검정색(`#111`)으로 통일
- 흰색 인쇄 배경에서 녹색 CRT 글자가 흐리게 보이던 문제 수정
- 입력 화면은 기존 DOS/CRT 검정 배경과 초록색 글자를 그대로 유지

## 주요 기능
- 기본 아이디어 3개, 최소 2개, 최대 10개
- 이전 활동 JSON 불러오기
- 아이디어 추가 및 삭제
- 4개 평가 기준별 1~5점 입력
- 총점 20점 자동 계산
- 최고점 및 공동 최고점 표시
- 최종 한 줄 아이디어 작성
- 브라우저 임시 저장, JSON 백업, A4 가로 PDF 출력

## 실행
`index.html`을 최신 브라우저에서 열면 바로 실행됩니다. `[ F4 ] PDF 출력/저장`을 누른 뒤 인쇄 창에서 `PDF로 저장`을 선택합니다.

## GitHub Pages
`index.html`과 `README.md`를 저장소 루트에 올린 뒤 Settings > Pages에서 main 브랜치 root를 배포 대상으로 지정합니다.
